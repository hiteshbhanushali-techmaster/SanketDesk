Frequently Asked Questions

Why Pure Windows Forms?

Windows Forms requires no external frameworks, adds zero MB of runtime dependencies, has minimal startup latency, and runs universally across Windows 7 SP1 through Windows 11 and Windows Server editions.

Does it wake the CPU when no alerts are shown?

No. The single animation clock stops completely when all toasts are dismissed. CPU usage is strictly 0.0%.

What happens during high burst alerts?

Under burst storms, BurstStrategy.CoalesceByKey updates the duplicate toast in-place to Title (N) without UI flashing, stacking, or allocating new form handles.

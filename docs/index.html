Pure Windows Forms Notification Suite

Zero-Dependency Desktop Notifications & Studio

Built exclusively using Windows Forms (GDI+). Handles 10,000+ alerts/sec bursts, runs on .NET Framework 4.6.1 and .NET 8.0, and stops completely (0% CPU) when idle.

Quick Start Installation

# For modern .NET 8.0 Windows desktop applications:
dotnet add package SanketDesk.Net8 --version 1.0.0

# For legacy .NET Framework 4.6.1+ applications:
dotnet add package SanketDesk.NetFramework --version 1.0.0

Initialization & Toast Submission

using Notifier;

// 1. Initialize once at application startup
Notifier.Initialize(new NotificationConfig
{
    HostForm = this,
    Position = NotificationPosition.BottomRight,
    BurstStrategy = BurstStrategy.CoalesceByKey
});

// 2. Submit alerts safely from any worker thread
Notifier.ShowSuccess("Feed Connected", "Market data stream online.");
Notifier.ShowError("Order Rejected", "Execution price breached limit.");

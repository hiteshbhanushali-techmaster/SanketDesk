SanketDesk Feature Guide

1. Pure Windows Forms Architecture

Zero external DLL dependencies. Single standalone assembly per runtime target with no WPF, MAUI, Avalonia, or Chromium runtime baggage.

2. Lock-Free Bounded Admission Controller

Thousands of concurrent producer threads submit alerts without blocking UI loops. Fast-path atomic CAS operations manage burst capacity.

3. Single Coordinated Clock

No per-toast timers. A centralized animation coordinator ticks only during active transitions and drops to 0.0% CPU when idle.

4. 6 Built-in GDI+ Visual Templates

ModernCard, MinimalBar, SolidAccent, SplitPill, ActionPrompt, and WindowsFluent with vector status glyphs and crisp DPI scaling.

5. Interactive PropertyGrid Configurator Studio

Full desktop designer with live PropertyGrid control inspection, real-time previewing, and automated C# initialization code generation.

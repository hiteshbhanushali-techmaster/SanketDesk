# Security Policy

## Supported Versions

| Version | Supported | Notes |
|---|---|---|
| `1.0.x` | :white_check_mark: | Current active release branch |
| `< 1.0.0` | :x: | Prerelease and historical iterations |

---

## Reporting a Vulnerability

The maintainers take security and stability seriously. If you discover a security vulnerability, security flaw, or denial-of-service issue in SanketDesk:

1. **Do NOT disclose the issue publicly** on GitHub Issues, Discussions, or social media.
2. Email a detailed vulnerability report privately to the maintainer:
   - **Contact:** [hiteshbhanushali.techmaster@gmail.com](mailto:hiteshbhanushali.techmaster@gmail.com)
3. Please include:
   - Component / class affected (e.g., `BoundedAdmissionController`, `HistoryService`).
   - Target framework (`net8.0-windows` or `net461`).
   - A minimal reproducible code example demonstrating the vulnerability.
   - Any proposed remediation or mitigation if known.

---

## Disclosure Response Timeline

- **Initial Response:** Within 48 hours of receiving your report.
- **Triage & Reproduction:** Within 5 business days.
- **Fix & Advisory:** A patch will be prepared and tested across all supported frameworks before publishing a security release and CVE/GHSA advisory.
